================
Numeric Literals
================
// 1. Valid Binary Literals
$0 $1 $01 $10010 $1010_0101 $1111_0000_1010_0101

// 2. Binary Error Cases
$ $123 $_01 $10_ $10__01

// 3. Valid Hexadecimal Literals
#0 #01 #2345 #6789 #abcdef #ABCDEF #ff_ff_ff_ff #1234_5678_9abc_def0

// 4. Hexadecimal Error Cases
# #12g #_ff #ff_ #ff__ff

// 5. Valid Decimal Integers & Separators
0 1234 1_000 1_234_567_890

// 6. Decimal Integer & Separator Error Cases
123_ 1__000 1_.2 12a3

// 7. Valid Decimal Magnitudes (Integer & Fractional)
1k 2M 3G 4T 5P 1m 2u 3n 4p 5f 1.5k 10.25u

// 8. Decimal Magnitude Error Cases
1km

// 9. Valid Floats & Scientific Notation

// 10. Float & Exponent Error Cases
1.2.3 1e5 1e+ 1e+2e+3 1e+a
